# 朱家驊研究資料

本倉庫是「朱家驊研究室」的資料來源真相，保存原始來源登記、OCR／目錄處理成果、研究筆記、公開資料模型與同步工具。

## 倉庫邊界

- 本倉庫：原始 PDF、OCR、頁碼對照、篇章目錄、人物／機構／主題索引、研究筆記與處理紀錄。
- `my-canvas-lab`：React 頁面、互動與一份經人工篩選後的公開 JSON 快照。
- 瀏覽器不會讀取本倉庫，也不會取得本機路徑。執行 `npm run sync` 後，前端只收到 `data/processed/zhu-jiahua-app.json` 的副本。

## 目前材料

第一批來源是王聿均、孫斌合編《朱家驊先生言論集》的 786 頁影像型 PDF。原檔留在使用者的私人藏書位置，不納入版本控制。人工校訂完成的逐篇原文可以進入公開資料與 Canvas；未校訂辨讀稿、書頁影像與本機路徑仍留在資料端。

## 指令

```sh
npm run validate
npm run sync
```

同步預設目標是相鄰的 `../my-canvas-lab/src/data/zhuJiahua.json`，亦可把自訂目標路徑作為腳本第一個參數。
