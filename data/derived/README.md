# 研究中資料

本目錄保存已由原書頁面核對、但尚未全部整理成公開頁面的研究資料。

- `toc_index.json`：**全書目次的權威篇目索引**，198 篇的篇名、原文日期與原書起頁，附部次／分節兩層結構。這是「全書有哪些篇、在第幾頁」的單一事實來源。
- `toc_full.md`：上一檔的人類可讀版，**由 `toc_index.json` 產生，不要直接編輯**。
- `speech_catalog.json`：已做篇級細目者的逐篇篇名、年代、文類與原書頁次（目前為正文前七篇）。
- `page_index.csv`：全書頁次、原書頁碼與篇章起訖的對照。
- `first-seven-reading-notes.md`：正文前七篇的初步內容觀察。
- `transcriptions/`：逐篇人工校訂原文；達「人工逐字核對」者可進公開資料與前端。

狀態值：

- `目次核對`：篇名、日期與起頁出自原書目次並逐欄放大核對過。**目次所載起頁不等於正文實際起頁**：相鄰兩篇共頁時目次只標一個起頁。
- `原頁核對`：篇名、日期與起頁已直接查看原書。
- `起訖核對`：另已確認下一篇起點，因此本篇終頁可定。
- `待續核`：起頁已確認，終頁或其他欄位仍待後頁核對。

原始逐頁辨讀稿與書頁影像留在 `data/materials/`，不進版本控制。

## 已知的未解問題

**PDF 頁次與原書頁碼的差值在全書中不是定值。** 兩個端點都直接看原頁核過：PDF 41 印著原書頁碼「一」（差 40）、PDF 342 印著「三〇三」（差 39）。原書頁 8 到 303 之間某處少一頁，位置尚未定位。

**原 PDF 仍在本機**（786 頁、46.6 MB），放在 repo 外的個人書庫目錄，依 `.gitignore` 不入庫，故 `data/raw/books/` 只有 `.gitkeep`——**那是設計如此，不是檔案遺失**。因此這個落差是可以定位的：對書頁 8 與 303 之間做二分搜尋，逐次算 PDF 頁與該頁印出的頁碼之差，差值從 40 變 39 的那一頁就是斷點。

因此 `toc_index.json` 目前只記原書頁碼、不記 PDF 頁次；等落差定位後可以補上換算。`data/materials/toc_ocr/README.md` 那份 30–40 頁的舊辨讀候選稿已被 `toc_index.json` 取代，它有數處篇名與頁碼錯誤，不要再拿它當來源。
