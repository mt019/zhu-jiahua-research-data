# 讀稿的人工校訂表

一篇一檔，檔名是篇號（`ZJH-004.tsv`）。每行四欄，以 TAB 分隔：

```
誤	正	原書頁	核對註記
```

第四欄選填。`#` 開頭與空行略過。

`build-reading-drafts.mjs` 在切完篇、跑完所有自動清理之後才套用這張表，所以第一欄寫的是
站上讀得到的那個樣子。每一條有兩道關卡，任一不過就中止建置：

- 在該篇全文命中的次數必須剛好一次。命中零次或多次都會安靜地改錯地方。
- 命中的位置必須落在第三欄所記的那一頁。第三欄記的是核對所依的原頁圖，
  頁對不上，表示核對所依的頁圖與命中的位置不是同一頁。

原頁圖的取法：`data/derived/page_map.json` 把原書頁換成 PDF 頁，再從原書 PDF 裁切
（`pdftoppm -f <頁> -l <頁> -r 1200 -png -x -y -W -H`）。直排右起，一欄一欄讀。

**沒有回原頁圖核過的字不進這張表。** 讀起來比較通順不是理由——辨讀錯字之所以難發現，
正是因為錯出來的字多半也通順。

## 分段的校訂

原書的分段靠首行縮排，辨讀稿在兩種情形下判錯：一句話被切成兩段，或兩段被接成一段。
兩種都用「¶」標段界，寫在誤欄或正欄——

- 接回一段（辨讀稿在換欄處掉了頭一兩個字，後一欄的第一個字看起來像縮排）：
  誤欄寫「爲運動¶形勢迥異」，正欄寫「爲運動戰，形勢迥異」。
- 切成兩段（原書另起一欄而辨讀稿接了下去，ZJH-160 的譯詩每一行在原書各起一欄）：
  誤欄寫「第二道是：」，正欄寫「¶第二道是：」。

**切段的誤欄從段界那個字寫起。** 頁碼記的是段落裡的字元位置，落在替換範圍中間的頁碼會被
挪到替換的起點；誤欄從段界起頭，該處的頁碼就落在起點上，不會偏。

## 全篇逐頁核過的篇

只改幾處錯字與「每一頁都比對過原頁圖」是兩件事，讀稿的 status 因此不看校訂表的條數，
看 `data/materials/speeches/reviewed.json`：一篇一條，記核過的起訖頁、日期與作法。
`validate-processed.mjs` 查那一條記的頁範圍與該篇的 `bookPages` 相同，也查兩邊不一致
（登記了而讀稿標著未校、或標著核過而沒有登記）。
