# 來源與公開政策

## 研究材料層

原始 PDF、頁面影像、逐頁中間檔、本機路徑及私人研究筆記留在本資料倉的非版本控制區或使用者原始藏書位置。未經人工校訂的辨讀全文也留在此層，不作正式原文。

## 公開層

可同步至 Canvas 的內容限於：

- 書目資料與材料技術狀態
- 自行整理的篇章索引、頁碼對照與統計
- 經人工逐字校訂、保留原書頁碼的篇章原文
- 短篇幅、具研究目的且可追溯的引文
- 自行撰寫的摘要、標記、比較與研究方法說明

本專案不存在「原文不得進前端」的限制。公開門檻是校訂狀態，不是篇幅：原文只要逐篇核對完成，即可完整公開。不得將未校訂辨讀稿、連續書頁影像、來源下載站字樣或本機絕對路徑放入公開 JSON。
